# External IRQ RB0 Interrupt

## Description
Uses the dedicated RB0/INT interrupt pin to toggle one LED immediately while the main loop continues blinking a second LED.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- Pushbutton
- 2 LEDs
- 2 x 330 ohm resistors
- 10 kohm resistor
- Breadboard and jumper wires

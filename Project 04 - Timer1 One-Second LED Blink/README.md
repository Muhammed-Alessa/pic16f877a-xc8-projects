# Timer1 One-Second LED Blink

## Description
Uses Timer1 interrupts instead of a long software delay. Sixteen 62.5 ms timer periods form a one-second LED toggle interval.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- LED
- 330 ohm resistor
- Breadboard and jumper wires

# Sine Waveform Generator - R-2R DAC

## Description
Outputs a 32-sample sine lookup table through an R-2R DAC to create an approximate 50 Hz sine waveform.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- 8-bit R-2R resistor ladder
- Oscilloscope
- Breadboard and jumper wires

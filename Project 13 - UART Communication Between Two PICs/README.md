# UART Communication Between Two PICs

## Description
Implements the course's MCU-to-MCU UART idea in one source file. Build once as the transmitter and once as the receiver by changing UART_ROLE_MASTER.

## Hardware
- 2 x PIC16F877A
- 2 x PICkit/programming setup as needed
- 2 x 4 MHz crystal
- 3 pushbuttons
- 8 LEDs
- Breadboards and jumper wires

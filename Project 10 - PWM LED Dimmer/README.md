# PWM LED Dimmer

## Description
Generates hardware PWM with CCP1/Timer2 and smoothly sweeps an LED through different brightness levels.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- LED
- 330 ohm resistor
- Breadboard and jumper wires

# Triangle Waveform Generator - R-2R DAC

## Description
Generates a triangular analogue waveform by ramping an 8-bit DAC code upward and then downward.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- 8-bit R-2R resistor ladder
- Oscilloscope
- Breadboard and jumper wires

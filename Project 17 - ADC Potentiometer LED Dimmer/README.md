# ADC Potentiometer LED Dimmer

## Description
Reads a potentiometer with the 10-bit ADC and maps the conversion result directly to CCP1 PWM duty cycle.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- 10 kohm potentiometer
- LED
- 330 ohm resistor
- Breadboard and jumper wires

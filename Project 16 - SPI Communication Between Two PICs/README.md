# SPI Communication Between Two PICs

## Description
Uses the PIC16F877A MSSP peripheral for an SPI master/slave link. Build the same file in master or slave mode with SPI_ROLE_MASTER.

## Hardware
- 2 x PIC16F877A
- 2 x 4 MHz crystal
- 8 LEDs
- 8 x 330 ohm resistors
- Breadboards and jumper wires

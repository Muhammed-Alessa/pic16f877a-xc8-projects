# CCP1 Capture Mode

## Description
Uses Timer1 as an external counter and captures its value on a rising edge at RC2/CCP1. Live counts and the captured value are shown on LED ports.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- 2 pushbuttons or pulse sources
- 16 LEDs
- 16 x 330 ohm resistors
- Breadboard and jumper wires

# Blinking LED - GPIO LAB

## Description
Configures a PIC16F877A GPIO pin as a digital output and blinks an LED with a fixed delay.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- LED
- 330 ohm resistor
- Breadboard and jumper wires

# Timer1 External Pulse Counter

## Description
Runs Timer1 in counter mode from the RC0/T1CKI input and displays the low eight bits of the hardware counter on PORTD LEDs.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- Pushbutton or digital pulse source
- 8 LEDs
- 8 x 330 ohm resistors
- Breadboard and jumper wires

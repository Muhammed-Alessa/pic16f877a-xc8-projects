# HC-SR04 Ultrasonic Distance Indicator

## Description
Measures the HC-SR04 echo pulse with Timer1 and shows a simple four-level distance indication on LEDs.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- HC-SR04 ultrasonic sensor
- 4 LEDs
- 4 x 330 ohm resistors
- Breadboard and jumper wires

# Adjustable Analog Voltage - R-2R DAC

## Description
Reads an analogue voltage with the PIC ADC and sends an 8-bit representation to an external R-2R resistor ladder on PORTB.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- 10 kohm potentiometer
- 8-bit R-2R resistor ladder
- Multimeter or oscilloscope
- Breadboard and jumper wires

# Sawtooth Waveform Generator - R-2R DAC

## Description
Generates a stepped sawtooth waveform by counting an 8-bit value upward and feeding it into an R-2R ladder DAC.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- 8-bit R-2R resistor ladder
- Oscilloscope
- Breadboard and jumper wires

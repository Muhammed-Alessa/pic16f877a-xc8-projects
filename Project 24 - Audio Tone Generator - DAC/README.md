# Audio Tone Generator - DAC

## Description
Uses the R-2R DAC output and a compact waveform table to generate simple audio tones. Four pushbuttons select four different tone periods.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- 8-bit R-2R resistor ladder
- 4 pushbuttons
- Small audio amplifier or buffered speaker input
- Breadboard and jumper wires

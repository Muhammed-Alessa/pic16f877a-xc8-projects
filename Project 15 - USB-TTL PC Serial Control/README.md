# USB-TTL PC Serial Control

## Description
Creates a UART link between the PIC16F877A and a PC through a USB-TTL converter. PC commands control two LEDs and the PIC reports the resulting state.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- USB-TTL serial converter
- 2 LEDs
- 2 x 330 ohm resistors
- Breadboard and jumper wires

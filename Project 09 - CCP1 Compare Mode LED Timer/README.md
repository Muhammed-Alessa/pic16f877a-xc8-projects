# CCP1 Compare Mode LED Timer

## Description
Uses CCP1 compare mode with Timer1 special-event resets. Ten 50 ms compare events create a 0.5-second LED toggle.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- LED
- 330 ohm resistor
- Breadboard and jumper wires

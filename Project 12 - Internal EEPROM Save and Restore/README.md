# Internal EEPROM Save and Restore

## Description
Stores a small LED value in the PIC16F877A internal EEPROM. One button changes and saves the value, while another reloads the saved value.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- 2 pushbuttons
- 3 LEDs
- 3 x 330 ohm resistors
- Breadboard and jumper wires

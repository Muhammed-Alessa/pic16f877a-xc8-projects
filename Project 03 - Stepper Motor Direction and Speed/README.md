# Stepper Motor Direction and Speed

## Description
Runs a unipolar stepper through a ULN2003-style driver, first forward and then reverse, using a simple four-step sequence.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- Unipolar stepper motor
- ULN2003 driver
- External low-voltage motor supply
- Breadboard and jumper wires

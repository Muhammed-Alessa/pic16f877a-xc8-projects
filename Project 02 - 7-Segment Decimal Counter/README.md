# 7-Segment Decimal Counter

## Description
Drives a common-cathode 7-segment display from PORTD and counts continuously from 0 to 9.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- 1-digit common-cathode 7-segment display
- 7 x 330 ohm resistors
- Breadboard and jumper wires

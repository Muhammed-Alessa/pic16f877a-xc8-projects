# Finger Snap Switch

## Description
Samples an amplified microphone signal with the ADC and toggles an LED when the measured level crosses a chosen threshold.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- Electret microphone
- Simple low-voltage microphone amplifier
- LED
- 330 ohm resistor
- Breadboard and jumper wires

# HC-05 Bluetooth LED Control

## Description
Receives simple UART commands from an HC-05 Bluetooth module and uses them to control LEDs on PORTD.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- HC-05 Bluetooth module
- 8 LEDs
- 8 x 330 ohm resistors
- Suitable logic-level interface
- Breadboard and jumper wires

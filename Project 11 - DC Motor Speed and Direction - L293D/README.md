# DC Motor Speed and Direction - L293D

## Description
Uses CCP1 PWM for motor speed and two L293D direction inputs. Pushbuttons select faster, slower, reverse, and stop operations.

## Hardware
- PIC16F877A
- PICkit 3
- 4 MHz crystal
- Small DC motor
- L293D motor-driver IC/module
- 4 pushbuttons
- External low-voltage motor supply
- Breadboard and jumper wires
